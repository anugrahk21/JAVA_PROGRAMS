## ⚙️ How to Use

1. **Clone the repository:**
    ```bash
    git clone https://github.com/anugrahk21/JAVA_PROGRAMS.git
    cd JAVA_PROGRAMS
    ```

2. **Compile and run a program:**
    ```bash
    javac ProgramName.java
    java ProgramName
    ```

3. **Requirements:**  
   - Java JDK 8 or higher  
   - No external libraries required for most programs
